# Security Policy

METRIA is an independent, read-only verification project. It is not an official Meteora product.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for the `accurastnya-hash/METRIA` repository. Include the affected version or commit, impact, reproduction steps, and any suggested mitigation. Do not publish secrets, seed phrases, access tokens, or a working exploit in a public issue.

There is no guaranteed response or remediation time. This repository is a hackathon-stage project and has not undergone an independent security audit. Do not rely on METRIA as the sole basis for financial or security decisions.
